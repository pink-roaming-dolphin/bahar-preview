BAHAR static staging export

This folder contains only public BAHAR pages and assets. It does not contain Produce or the private Honeycomb archive. The Honeycomb download belongs in private owner storage, never in a public hosting folder.

Serve this folder at the /bahar-preview/ path (for a GitHub Pages project repository) to test it. Opening index.html directly as a file will not resolve its images and links. The staging version contains noindex instructions. Do not connect baharadogru.com or cancel the old Squarespace hosting until the independent staging site is visually reviewed on desktop and mobile.

Alias pages use HTML refresh. A chosen host may need permanent HTTP redirect rules for old aliases. Honeycomb's four former URLs are deliberately absent and should return 404.
